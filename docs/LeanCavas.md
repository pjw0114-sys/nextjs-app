## 세부 내용

### 1. 문제 (Problem)

- 정기 취미 모임(수영/헬스/러닝 등) 주최자는 매회 공지, 참여자 관리(참석 여부 체크), 카풀 조율, 비용 정산을 반복적으로 수동 처리해야 한다.
- 공지와 참석 응답이 카카오톡 채팅방에서 뒤섞여 흐름을 놓치기 쉽고, 누가 참석하는지 파악이 늦어진다.
- 카풀 매칭과 비용 분담/납부 확인은 특히 수작업(엑셀, 계좌 확인)에 의존해 주최자 부담이 크다.

**기존 대안 (Existing Alternatives)**

- 카카오톡 단체 채팅방: 공지와 대화가 뒤섞이고 참석 여부 취합이 어려움
- 구글폼 등 별도 설문: 공지와 분리되어 있어 참여자가 별도로 확인·응답해야 함
- 엑셀/수기 정산: 참석자 수 변경 시 재계산 필요, 납부 여부 확인을 개별로 추적
- 전화·문자: 카풀 탑승 조율을 개별적으로 처리

### 2. 솔루션 (Solution)

PRD 기능 명세(F001~F014) 기준:

- 모임 생성 및 초대코드로 참여 (F001~F004)
- 회차(이벤트) 단위 공지 등록 및 RSVP 응답, 마감/정원 처리, 응답 현황 집계 (F005~F008)
- 카풀 차량 등록·탑승 신청·확정 (F009~F011)
- 비용 항목 입력 시 참석 확정 인원 기준 1인당 금액 자동 계산, 납부 완료 체크 (F012~F013)
- 앱 접속 시 확인하는 웹 알림함 (F014)

**핵심지표 (Key Metrics)**

- 모임(그룹) 생성 수 / 모임당 평균 이벤트(회차) 생성 수
- RSVP 응답률(참석/불참 응답 인원 ÷ 전체 멤버)
- 카풀 매칭 성공률(탑승 확정 ÷ 탑승 신청)
- 정산 납부 체크 완료율
- 주최자 기준 주간 재방문율(재사용 여부 판단 지표)

### 3. 고유가치제안 (Unique Value Proposition)

카카오톡·엑셀·개별 연락으로 흩어져 있던 모임 운영 업무(공지·참석 체크·카풀·정산)를 하나의 웹 서비스에서 처리해, 총무(주최자) 1명의 반복적인 관리 부담을 가장 크게 줄여준다.

**상위 개념 (High Level Concept)**

- "정기 모임을 위한 카카오톡 대체 운영 허브"
- 비유: "동호회의 Notion + 정산기 + 카풀 조율 도구"

### 4. 경쟁우위 (Unfair Advantage) ⚠️ 추정

PRD에 명시된 근거가 없어 아래는 가설 수준이다. MVP 단계에서는 뚜렷한 unfair advantage가 없다고 보는 것이 정직하다.

- 초기에는 "공지+RSVP+카풀+정산 통합"이라는 기능적 차별점 외에 진입장벽이 없음
- 향후 특정 동호회 네트워크(예: 러닝크루 커뮤니티)를 통한 초기 사용자 록인, 누적 사용 데이터(모임 운영 이력) 정도가 방어 요소가 될 수 있음 — 검증 필요

### 5. 고객 세그먼트 (Customer Segments)

- 주 타깃: 소규모 정기 취미 모임(수영/헬스/러닝 등)을 운영하는 주최자 1명
- 부 타깃: 해당 모임에 고정적으로 참여하며 매회 참석 여부만 체크하면 되는 참여자들

**얼리어답터 (Early Adopters)**

- 이미 카카오톡 단체방으로 모임을 운영 중이며, 정산과 카풀 조율에 특히 시간을 많이 쓰는 총무형 주최자(러닝크루, 수영모임, 등산모임 등)

### 6. 채널 (Channels) ⚠️ 추정

PRD는 "초대코드/링크를 카카오톡 등 외부로 직접 공유"한다고만 명시(F002). 신규 사용자 유입 채널은 별도 정의되어 있지 않아 아래는 가설이다.

- 기존 모임의 카카오톡 오픈채팅방에 초대링크 공유(입소문 기반)
- 동호회 카페/밴드, 지역 체육시설(수영장·헬스장) 게시판
- 인스타그램 등 SNS를 통한 동호회 계정 홍보

### 7. 수익원 (Revenue Streams) ⚠️ 추정

- PRD 기준 MVP는 무료 서비스다. 결제/송금 연동은 "MVP 이후 기능"으로 명시되어 있어(F012~F013은 안내·체크만, 실제 송금은 외부 처리) 현재 수익 모델이 없다.
- 향후 후보(검증 필요): 참여자 수 제한 해제, 광고 제거, 정산 자동 이체 연동 수수료 등 프리미엄 전환

### 8. 비용 구조 (Cost Structure)

- 인프라: Vercel 배포 + MariaDB 호스팅, 도메인 비용
- 인증: Google OAuth(무료 티어 사용, `src/lib/google-oauth.ts` 기준 외부 유료 SDK 없음)
- 인건비: 1인 개발 기준 개발/운영 시간
- ⚠️ MVP 이후: 알림 외부 발송(이메일/푸시) 도입 시 발송 비용 추가 예상
