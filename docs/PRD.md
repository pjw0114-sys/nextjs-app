# 동네모임 MVP PRD

## 🎯 핵심 정보

**목적**: 소규모 정기 취미 모임(수영/헬스/러닝 등) 주최자가 모임 생성부터 회차별 공지, 참석 응답, 카풀, 정산 안내까지 한 곳에서 처리하게 한다.
**사용자**: 고정 인원의 정기 모임을 운영하는 주최자 1명과, 매회 참석 여부만 체크하면 되는 참여자들.

## 🚶 사용자 여정

```
[비로그인]
  로그인 페이지 ──(회원가입 클릭)──▶ 회원가입 페이지
    │  (이메일/비번 or Google 로그인 성공)         │ (가입 성공 시 자동 로그인)
    ▼                                              │
  모임 목록 페이지 ◀─────────────────────────────────┘
    │
    ├─(새 모임 만들기 / 초대코드로 참여)──▶ 모임 생성·참여 페이지
    │                                        │ (생성/참여 완료 시 자동 이동)
    │                                        ▼
    └─(기존 모임 카드 클릭)───────────────▶ 모임 상세 페이지
                                               │
                        ┌──────────────────────┼───────────────────────┐
                        ▼(주최자만)             ▼                       ▼
                  이벤트 생성 페이지      이벤트 목록에서 회차 클릭      참여자 관리(같은 페이지 내)
                        │                      │
                        └───(등록 완료)────────▶ 이벤트 상세 페이지
                                                 │  ├─ RSVP 마감 전: 참석/불참 응답 가능
                                                 │  └─ RSVP 마감 후: 응답 버튼 자동 비활성화
                                                 │
                                     ┌───────────┴───────────┐
                                     ▼                       ▼
                              카풀 관리 페이지           정산 관리 페이지
                          (차량등록/탑승신청/확정)   (비용등록·1인당 금액 자동계산/납부체크)
                                     │                       │
                                     └────(뒤로가기)──────────┘
                                                 ▼
                                        이벤트 상세 페이지로 복귀

[헤더 어디서나] 알림함 페이지 ──(알림 클릭, 딥링크)──▶ 관련 이벤트 상세 / 카풀 / 정산 페이지
```

- **자동 리디렉션**: 로그인 성공 → 모임 목록 / 회원가입 성공 → 자동 로그인 후 모임 목록 / RSVP 마감시각 도달 → 응답 버튼 자동 잠금
- **선택 분기점**: 로그인 방식(이메일/비번 vs Google) / 모임 목록에서 생성 vs 참여 / 역할에 따른 화면 차이(주최자: 이벤트 생성·참여자 관리·비용 등록 가능 / 참여자: RSVP·탑승신청·납부체크만 가능)

## ⚡ 기능 명세

| ---- | -------------------------------------- | --------------------------------------------------------------------- | ---------------------------------- | --------------------- |

| F004 | 참여자 목록 관리                       | 주최자가 참여자 목록 조회 및 강제 탈퇴 처리                           | 모임 운영 최소 관리 기능           | 모임 상세 페이지      |
| F005 | 이벤트(회차) 생성                      | 제목/일시/장소/공지내용/RSVP 마감/정원 입력해 회차 등록               | 정기 모임의 핵심 단위              | 이벤트 생성 페이지    |
| F006 | 이벤트 공지 확인                       | 참여자가 회차의 일시/장소/공지 내용 확인                              | 참석 판단의 기본 정보              | 이벤트 상세 페이지    |
| F007 | RSVP 응답                              | 참석/불참 선택 응답, 마감 후 응답 불가, 정원 초과 시 마감             | 참석 인원 확정의 핵심              | 이벤트 상세 페이지    |
| F008 | RSVP 현황 집계                         | 주최자가 참석/불참/미응답 인원 집계 확인                              | 준비물·정산 산정 기준              | 이벤트 상세 페이지    |
| F009 | 차량 등록                              | 운전자가 출발지, 탑승 가능 인원 등록                                  | 카풀 매칭의 시작점                 | 카풀 관리 페이지      |
| F010 | 탑승 신청                              | 참여자가 등록된 차량에 탑승 신청                                      | 카풀 수요 접수                     | 카풀 관리 페이지      |
| F011 | 탑승 확정                              | 운전자가 탑승 신청을 수락/거절해 확정                                 | 실제 탑승 인원 확정                | 카풀 관리 페이지      |
| F012 | 비용 항목 입력 및 1인당 금액 자동 계산 | 비용 항목/총액 입력 시 참석 확정 인원 기준 1인당 금액 자동 계산       | 정산 안내의 핵심, 수동 계산 제거   | 정산 관리 페이지      |
| F013 | 납부 완료 체크                         | 참여자가 본인 납부 여부를 "완료"로 체크, 주최자는 전체 납부 현황 확인 | 실제 송금은 외부 처리, 앱은 확인만 | 정산 관리 페이지      |
| F014 | 웹 알림함                              | RSVP 마감 임박, 카풀 확정, 정산 등록 등을 앱 접속 시 목록으로 확인    | 별도 발송 없이 최소한의 인지 수단  | 알림함 페이지         |

### 3. MVP 이후 기능 (제외)

- 알림 외부 발송(이메일/푸시/실시간 웹소켓)
- 실제 결제/송금(카카오페이 등) 연동
- 상세 프로필 편집, 프로필 이미지
- 모임/이벤트별 알림 설정(끄기·주기 설정)
- 반복 이벤트 자동 생성(매주 자동 등록)
- 참여자 간 채팅/댓글
- 참석률·비용 통계 리포트

## 📱 메뉴 구조

```
[로그인 전]
├─ 로그인 (F016, F017)
└─ 회원가입 (F015)

[로그인 후 - 헤더 공통 메뉴]
├─ 내 모임 (모임 목록 페이지)
│   ├─ 새 모임 만들기 / 초대코드로 참여 (F001, F003) → 모임 생성·참여 페이지
│   └─ 모임 카드 클릭 → 모임 상세 페이지
│       ├─ 초대코드 확인/공유 (F002)
│       ├─ 참여자 관리 [주최자 전용] (F004)
│       ├─ 이벤트 만들기 [주최자 전용] (F005) → 이벤트 생성 페이지
│       └─ 이벤트 목록 클릭 → 이벤트 상세 페이지
│           ├─ 공지 확인 (F006)
│           ├─ RSVP 응답 (F007)
│           ├─ RSVP 현황 집계 [주최자 전용] (F008)
│           ├─ 카풀 (F009, F010, F011) → 카풀 관리 페이지
│           └─ 정산 (F012, F013) → 정산 관리 페이지
└─ 알림함 (F014)
```

## 🛠️ 기술 스택 (최신 버전)

- **프론트엔드**: Next.js 16.3.1 (App Router, Turbopack 기본 활성화), React 19.2
- **스타일링**: Tailwind CSS v4 (CSS 기반 설정, `@theme inline`)
- **UI 컴포넌트**: shadcn/ui(`style: base-nova`, Base UI(`@base-ui/react`) 기반), lucide-react(아이콘), class-variance-authority(변형 관리)
- **폼/검증**: 별도 라이브러리 없이 controlled input + 서버측 수동 검증
- **백엔드/DB**: Next.js Route Handler + MariaDB(mariadb 드라이버 커넥션 풀), Node `crypto.scrypt` 기반 비밀번호 해싱
- **배포**: Vercel
- **패키지 관리**: npm
